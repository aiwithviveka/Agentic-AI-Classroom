## What is this?

**Agentic AI Classroom** is a free, self-paced learning platform for **Agentic AI, LLMOps, AI Support, and AI Consulting** — built for students, interns, freshers, and working engineers alike. It combines short conceptual notes, live interactive examples, and runnable code for every topic in the curriculum, plus an interactive whiteboard to walk through each idea step by step.

**Who it's for:**
- 🎓 **Students & freshers** starting their Agentic AI journey
- 🧑‍💻 **Working engineers** (LLMOps / AI Support / AI Consulting) leveling up
- 🧭 **Interview candidates** prepping with role-based question banks
- 🏗️ **Builders** who want to browse real, working agent implementations

## ⚡ Get Started

No installs needed — the classroom runs entirely in your browser.

```bash
# Just open the live site
https://aiwithviveka.github.io/Agentic-AI-Classroom/
```

1. Pick a topic from the **Curriculum** panel on the left
2. Read the notes, walk through the live example
3. Use the **Whiteboard** to sketch out the concept yourself
4. Say **"next series"** any time to unlock the next part

> Parts I–II are live now (Beginner). Part III — RAG, embeddings, tools & MCP — is coming next.
